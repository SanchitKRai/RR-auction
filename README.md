## 🏆 Project Overview

This repository houses the complete analytical framework, statistical models, interactive web dashboard, and official 9-page executive PDF scouting dossier engineered for **Rajasthan Royals' War Room** leading into the **IPL 2027 Auction**.

By analyzing **200,999 deliveries** across **867 contested matches** (883 scheduled) in the 2022–2026 IPL and T20 International cycle, this platform introduces a context-aware **Multi-Factor Pressure Index ($PI \in [0, 100]$)** and **Pressure Reliability Score (PRS)** calibrated with Bayesian shrinkage ($k=80$) and tournament quality weights.

## 🔍 Data Quality, Audit & Reconciliation Transparency

### Match Count Reconciliation (883 Scheduled = 867 Contested + 16 Abandoned)
* **`matches.csv`:** Contains **883 scheduled matches**.
* **`ball_by_ball.csv`:** Contains deliveries from **867 contested matches** (200,999 valid balls).
* **Audit Verification:** Exactly **16 matches** were abandoned without a ball bowled due to inclement weather and persistent rain washouts (Match IDs: `31281, 31284, 31288, 32610, 32612, 32622, 38797, 36564, 36210, 40761, 41502, 41503, 42030, 46008, 48513, 50189`).
* **Audit Equation:** $$883\text{ Scheduled} = 867\text{ Contested} + 16\text{ Abandoned}$$

### Win Probability Added (WPA) Coverage
* **Chasing States (47.4% total balls, 48.9% HP balls):** Modeled on **95,272 deliveries** via logistic regression ($AUC = 0.8966, \text{Log-Loss} = 0.4018$).
* **First-Innings Deliveries (105,727 balls):** Evaluated through Crisis State Par (&le;30/3) and Death Par benchmarks.
* **Fair Comparisons:** All WPA rates use the **chase-delivery denominator**, eliminating false dilution.

# RR WAR ROOM — Final Upgrade V3 asset pack

This package adds the decorative layers that were missing from the last implementation. It does not include official RR/IPL trademark artwork or real player cut-outs; those must come from approved source files.

## New reusable SVG assets

### Player-card backplates (`assets/player_card_backplates/`)
- `card_batter_backplate.svg` — magenta/oxblood palace haze
- `card_finisher_backplate.svg` — amber/gold palace haze
- `card_death_backplate.svg` — violet/magenta palace haze
- `card_spin_backplate.svg` — royal-blue palace haze
- `card_batter_scene_ai.png`, `card_finisher_scene_ai.png`, `card_death_scene_ai.png`, `card_spin_scene_ai.png` — separate colour-graded AI-generated Jaipur-palace-inspired scenic plates; these are decorative atmosphere, not documentary photographs of Hawa Mahal.
- `player_card_lower_vignette.svg` — lower fade so text sits on a dark readable area
- `player_card_gradient_border.svg` — subtle gradient outline

### Chart glow (`assets/chart_glow/`)
- `chart_panel_ambient_glow.svg` — ambient pink/blue chart panel light
- `radar_plot_glow.svg` — radial/polygon chart backdrop illumination
- `donut_outer_halo.svg` — outer glow only; donut segments remain data-driven
- `chart_data_point_glow.svg` — reusable glowing data-point sprite

### Hero and sidebar (`assets/hero_and_sidebar/`)
- `hero_left_gradient_overlay.svg` — dark text-safe hero overlay
- `sidebar_photo_vignette.svg` — readable footer overlay for a real palace photo
- `royal_flag_wave_generic.svg` — waving fabric illustration with generic crest; replace with approved RR flag/logo if available
- `optional_ai_jaipur_palace_atmosphere.png` — AI-generated mood plate, not a documentary photograph and not an exact Hawa Mahal photo

### KPI icons (`assets/kpi_icons/`)
Consistent outlined icons: target, cricket ball, lightning, model network and trophy.

### Role badges (`assets/role_badges/`)
Four role-colour badge backgrounds. Keep the badge copy as live text.

### Reference crops (`reference_only/`)
Low-resolution crops from the user-provided original screenshot. Use only to compare placement, colour and crop; do not use as production photography.

## Not included deliberately
- Official Rajasthan Royals logo/flag: use authorized brand artwork; generic SVG is only a placeholder.
- Official IPL logo: do not invent or recreate it. The supplied original dashboard reference does not show a separate IPL-logo watermark behind the charts.
- Named player photographs/cut-outs: use approved/licensed player images. Remove white backgrounds to transparent PNGs; do not generate player likenesses.

## Consolidated earlier assets
The `legacy_supporting_assets/` folder retains all 28 SVGs from the earlier asset kit (original and supplemental folders), so this V3 package is cumulative. Prefer the newer V3 versions where names/functions overlap, but keep legacy assets available for existing app references.

# RR War Room — SVG asset pack

A small, editable SVG asset kit for recreating the premium dark cricket analytics dashboard.

## Included
- `rrw_crest.svg` — generic royal cricket crest (not an official Rajasthan Royals logo)
- `palace_silhouette.svg` — decorative palace skyline
- `stadium_glow.svg` — dark atmospheric background
- `royal_pattern.svg` — subtle ornamental texture
- `icon_*.svg` — KPI and navigation icons
- `card_*_bg.svg` — four role-specific player-card backgrounds

## Use in Power BI
1. Import SVGs as images where your Power BI version/visual supports SVG.
2. For SVG data URIs in DAX, encode the SVG as a data URI and use an Image URL field category where supported.
3. For HTML visuals, reference the SVG files or inline their markup.
4. Overlay real player photography separately; use only licensed/approved player images.
5. Set the canvas to `#090E22`; suggested accents: magenta `#F02D9B`, royal blue `#5C9DFF`, gold `#F4C95D`, mint `#35E6A1`.

All assets are vector SVG and can be edited in Figma, Illustrator, Inkscape, or a code editor.
